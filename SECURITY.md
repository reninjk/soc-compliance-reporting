# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub Issue for security vulnerabilities.**

### How to Report

1. **Email:** [security@your-organisation.com]
2. **Subject line:** `[SECURITY] soc-compliance-reporting — <brief description>`
3. **Include:** Description, reproduction steps, potential impact

We acknowledge within **48 hours** and provide a status update within **7 days**.

## Scope

- Accidentally committed audit findings tied to real systems or assets
- Templates containing real control failure evidence
- Any PII or sensitive internal data inadvertently included

## Critical Rules

- All templates use placeholder values only — never real audit results
- No internal system names, asset lists, or real gap findings
- Compliance scores and metrics use fictional example values only

## Responsible Disclosure

We will not pursue legal action against good-faith researchers. Credit given unless anonymity preferred.
